# 🌸 Rakesh & Nandita - Assamese Royal Wedding Invitation 🌸

An interactive, culturally rich Assamese wedding invitation web application celebrating the holy union of **Rakesh & Nandita**.

---

## ✨ Features
- **Traditional Assamese Aesthetics**: Kingkhap borders, Jaapi, Xorai, Dhol & Pepa motifs, and Saki lamps.
- **Custom Authentic Fonts**: Traditional calligraphy font for sacred mantras (*Teesta*) and royal title font (*Rangpur*).
- **Interactive Saki Lighting**: Guests can light virtual earthen lamps with realistic flickering glow.
- **Interactive Scratch-to-Reveal Date**: Royal gold scratch card revealing the auspicious wedding date.
- **Bilingual Experience**: Smooth toggle between Assamese (অসমীয়া) and English.
- **Live Wedding Countdown**: Real-time timer with Assamese numeral conversion.
- **Shehnai & Bamboo Flute Melodies**: Built-in Web Audio API synthesizer playing traditional Raag Bhupali wedding notes (zero external audio downloads required).
- **Floating Kopou Orchid & Marigold Petals**: Smooth physics-based falling petals.
- **Direct Calendar Integration**: One-click Google Calendar add for Jurun, Wedding, and Reception.
- **Guest Wishes Wall**: Interactive guestbook for friends and family to leave heartfelt blessings.
- **Venue & Google Map QR Code**: Location card featuring Charingia Gaon, Jorhat and a scannable QR code.
- **1-Click WhatsApp Sharing**: Floating share button to send customized invitations to family and friends.

## 🚀 How to Host on GitHub Pages (Free & Instant)

### Step 1: Create a New GitHub Repository
1. Log in to [GitHub](https://github.com/).
2. Click **New** to create a new repository (e.g. `wedding-invitation`).
3. Leave it Public, and do **not** initialize with README or license (they are already prepared here).

### Step 2: Push this Project to GitHub
Open your terminal (PowerShell or Git Bash) in this project folder and run:

```bash
git init
git add .
git commit -m "Initial commit: Rakesh and Nandita wedding invitation"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/YOUR_REPO_NAME.git
git push -u origin main
```
*(Replace `YOUR_GITHUB_USERNAME` and `YOUR_REPO_NAME` with your actual GitHub username and repository name).*

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** (gear icon) > **Pages** (in the left sidebar).
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` (or `master`) and `/ (root)` folder.
4. Click **Save**.

Your invitation website will be live in ~1-2 minutes at:
`https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPO_NAME/`
